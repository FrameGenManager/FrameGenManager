# FrameGenManager

**FrameGenManager** is the Windows RTX frame-generation manager (pandaligx): scan games, pick a scheme, deploy 2X-6X.

## How to use
1. Download v4.1.2.
2. Extract `FrameGenManager.zip`.
3. Run the exe. Enable HAGS.
4. Scan a game, pick scheme, install. Turn on FG in-game.

## FAQ

**Vulkan?**
0.2.6 schemes include Vulkan. 0.3.1 is D3D12.

**Anti-cheat?**
Exit the game before install/uninstall. Notes in `files/notes/`.

## Requirements
Windows 10/11 x64. RTX 20/30. HAGS on.
